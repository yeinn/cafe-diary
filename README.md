# 카페일기 cafe-diary

카페에서 보낸 시간을 기록하는 웹사이트입니다.\
단순히 마신 음료를 적는 것에 그치지 않고, 카페에서 보낸 모든 경험을 남길 수 있습니다.\
기록이 쌓일수록 나의 취향도 한눈에 확인할 수 있습니다.

## 프로젝트 배경

회사에서 일하다가 점심시간이 되면 카페로 향했습니다. 잠시 업무에서 벗어나 나에게 집중하며 쉬어가는 시간을 보냈습니다.\
좋아하는 음료를 마시며 책을 읽고, 떠오르는 생각이나 인상 깊었던 문장을 적었습니다. 때로는 미래에 대한 고민을 일기로 남기기도 했습니다.\
이러한 시간이 쌓이면서 어느새 하나의 습관으로 자리 잡았습니다. 기록이 늘어날수록 지난 기록을 다시 꺼내 보고 싶어졌지만,\
종이 다이어리로는 한계가 있었습니다.

- 지면이 작아서 적을 수 있는 양이 한정되어 있다.
- 사진을 붙일 수 없어 그날의 분위기를 남기기 어렵다.
- 카페 메모, 책 문장, 일기가 한 페이지에 뒤섞여 나중에 다시 찾아보기 어렵다.

그래서 이 기록을 웹으로 옮기기로 했습니다.\
항목별로 나눠 적고, 사진을 첨부하고, 쌓인 기록을 달력과 취향 통계로 다시 볼 수 있게 했습니다.\
PC와 모바일 상관없이 편하게 기록할 수 있도록 반응형으로 구성했습니다.

> 사이트에 보이는 기록은 샘플 데이터이며, 일부는 실제로 촬영하고 작성한 것입니다.

## 주요 기능

**홈**

- 월간/주간 달력 보기
- 기록이 있는 날짜에 컵 아이콘 표시, 카페를 처음 방문한 날에는 NEW 뱃지 표시
- 날짜를 선택하면 그날의 기록 목록 표시 (모바일에서는 바텀시트로 열림)
- 모든 기록 목록: 최신순/오래된순 정렬, 8개 초과 시 전체보기

**기록 작성**

- 필수 입력: 카페 이름과 음료 또는 디저트 중 하나 이상
- 방문 날짜, 날씨, '다시 가고 싶은 카페' 표시
- 이전에 기록한 카페 이름 자동완성, 첫 방문 / n번째 방문 안내
- 선택 입력: 사진(기록당 최대 3장), 함께한 책(제목 · 읽은 쪽수 · 표지 사진), 인상 깊은 문장, 오늘의 글쓰기, 한줄평(최대 5개, 아이콘 선택)
- 첨부한 사진은 긴 변 1080px로 줄여 저장
- 작성 중 닫기를 누르면 저장되지 않는다는 확인창 표시

**기록 상세**

- 사진 슬라이더(버튼과 스와이프), 메뉴, 책, 문장, 글, 한줄평 표시
- 수정하기, 삭제하기(확인창 후 삭제)

**취향 아카이브**

- 전체 / 올해 / 이번 달 기간별 집계
- 이달의 나 한 줄 요약, 방문한 카페 수와 함께한 책 수
- 자주 간 카페(도장판), 자주 마신 음료와 디저트 순위, 다시 가고 싶은 카페, 함께한 책 목록

## 사용 기술

- 디자인 : 와이어프레임 이후 UI 디자인은 직접 편집 (Figma)
- 데이터 저장: 브라우저 `localStorage`
